# داووس کارتینگ — اپ مدیریت (Flutter)

اپلیکیشن موبایل برای کنترل همهٔ بخش‌های پنل مدیریت سایت: داشبورد، رزروها و سانس‌ها (ثبت حضوری، لغو، ورود مشتری)،
مشتریان، پرداخت‌ها، پیامک، دستیار هوشمند، تنظیمات و قیمت‌ها، حسابداری کامل، وضعیت سرویس‌ها و کاربران پنل با
سطح دسترسی. همهٔ متن‌ها فارسی و راست‌به‌چپ و تاریخ‌ها شمسی‌اند.

ساختار و کتابخانه‌ها مثل اپ Vesta است: GetX (وضعیت، مسیریابی، تزریق وابستگی)، Dio، GetStorage و
flutter_secure_storage، fl_chart و shamsi_date.

## طراحی و گردش‌کار

مفهوم طراحی «دیوار پیت» است: تابلوی زمان‌سنجی یک پیست. کربن تیره (و نسخهٔ روشن)، زرد کهربایی فقط برای کار اصلی،
اعداد درشت، بلیت‌هایی شبیه بلیت واقعی. برنامه حول کارهای روزانهٔ پیست ساخته شده، نه حول فهرست منوهای پنل:

- **امروز:** بلیت‌ها، چند نفر وارد شده‌اند، سانس بعدی، هشدارها (سرویس خراب، اعتبار پیامک، رزرو در انتظار پرداخت) و میانبرها.
- **رزروها:** نوار روزها، خط زمانی سانس‌ها با حلقهٔ ظرفیت و زیر هر سانس بلیت‌هایش؛ ورود مشتری و لغو روی خود بلیت.
- **دکمهٔ وسط (فروش بلیت):** فروش حضوری در یک صفحه: روز، سانس، خودرو، روش پرداخت؛ مبلغ پایین صفحه و صدور بلیت.
- **جستجوی بلیت:** با شمارهٔ بلیت، موبایل یا نام همان‌جا که تایپ می‌کنید نتیجه می‌آید و ورود مشتری ثبت می‌شود.
- **مالی:** نقدینگی، این ماه، میانبر هزینه/درآمد/انتقال/پرداخت و بخش‌های حسابداری؛ مبالغ را می‌توان پنهان کرد.
- **بیشتر:** مشتریان، پرداخت‌ها، پیامک، دستیار، تنظیمات، وضعیت سرویس‌ها، کاربران و حساب خود.

نوار پایین فقط تب‌هایی را نشان می‌دهد که دسترسی‌اش را دارید.

## ساختار

```
lib/
  core/constants/urls.dart        همهٔ نشانی‌های API (مثل Vesta: ثابت‌های کامل، بدون baseUrl در Dio)
  core/constants/named_routs.dart نام مسیرها
  core/services/api_service/      یک Dio تکی؛ هر بخش در یک part جدا
  core/interceptors/              نگه‌داری کوکی نشست و ارسال CSRF
  core/theme/, core/utils/        تم، قالب‌بندی عدد و تاریخ شمسی، شروع برنامه
  features/<بخش>/{model,controller,page}
  shared/                         ویجت‌ها و کنترلرهای مشترک
```

افزودن بخش تازه: دسترسی‌اش را در سرور بسازید، یک ردیف در `features/home/model/admin_section.dart` اضافه کنید، صفحه و
کنترلرش را در `core/utils/admin_app.dart` ثبت کنید.

## اجرا

نشانی سرور هنگام ساخت تعیین می‌شود (پیش‌فرض `https://davoskarting.ir`):

```bash
flutter pub get
flutter run --dart-define=API_DOMAIN=https://davoskarting.ir
# سرور محلی از شبیه‌ساز اندروید:
flutter run --dart-define=API_DOMAIN=http://10.0.2.2:8088
```

ورود با همان نام کاربری و رمز پنل وب است. نشست در کوکی نگه داشته می‌شود و اپ آن را (به‌همراه توکن CSRF) در
حافظهٔ امن گوشی ذخیره می‌کند؛ سرور هیچ تغییری لازم ندارد.

## iOS

ساخت iOS فقط با Xcode روی macOS ممکن است؛ این کار روی سرورهای macOS خود گیت‌هاب انجام می‌شود
(`.github/workflows/admin-app-ios.yml`). از تب Actions گزینهٔ «admin-app-ios» را اجرا کنید و فایل `davos-admin-ios` را
دانلود کنید. بدون اکانت توسعه‌دهندهٔ اپل خروجی «امضا‌نشده» است و باید با Sideloadly یا AltStore (یا Xcode) امضا و نصب شود.
با تنظیم چهار secret که بالای فایل workflow نوشته شده، خروجی امضاشده (ad-hoc) ساخته می‌شود.
